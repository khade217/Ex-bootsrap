# Ex-bootsrap - Modern Open Source Landing Page

This project delivers a professional, modern landing page built using [Bootstrap 5](https://getbootstrap.com/), custom advanced CSS, and interactive JavaScript via jQuery. The UI showcases open-source alternatives to popular digital tools, with an emphasis on elegance, accessibility, and expandability.

## ✨ Features

- **Bootstrap 5.3** via CDN: Responsive grid and clean UI
- **Advanced CSS** (`styles.css`): Glassmorphism, gradients, SVG effects, parallax accents, and glowing typography
- **Cards Gallery**: Each card highlights an open-source project and its commercial alternative
- **Fully Responsive** and accessible
- **Animations**: Subtle hover/shadow, fade/slide, parallax ornaments with jQuery/JS

## 📦 Included Files

- `index.html` &mdash; main landing page/root
- `styles.css` &mdash; custom advanced theme and style
- `README.md` (this file)

## 🚀 Quick Start

1. **Clone the repo** or upload the files to your Github repository:
    ```sh
    git clone https://github.com/khade217/Ex-bootsrap.git
    ```
2. **Open `index.html` in your browser** or deploy using GitHub Pages or any static hosting.
3. **Personalize**: Edit the cards/content in `index.html` and update theme/colors in `styles.css` as needed.

## 🛠️ Customization
- To add more cards, copy and paste a card `<div>` in the `.gallery-section`.
- Update styles in `styles.css` for brand colors, gradients, ornaments, or even CSS variables.

## 🌐 Deployment
This site works great with [GitHub Pages](https://pages.github.com/):
- Go to your repo settings > Pages
- Select the branch and `/ (root)` for deployment
- Save and use the generated link
